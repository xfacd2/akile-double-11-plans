## 真实成本：小字部分比标价重要

**超流量不是停机，是限速。** 所有套餐流量用完后限速到共享 10Mbps，不断机、不额外扣费。10Mbps 大概能跑 1.2MB/s，看 1080p 够，多设备同时用会卡。想恢复原速要买流量重置，普通节点 ¥7/次，香港节点 ¥10/次。

**5GB 磁盘是真小。** 从香港到日本到新加坡，入门档清一色 5GB。装个系统、跑个代理、放个解锁脚本没问题；一旦开始存日志、做缓存、跑 Docker 镜像，很快就满。要跑实际业务，直接看 JPHyper-Lite 的 10GB 或 LAX Pro 的 20GB 起。

**币种混用。** 官网下单页部分套餐以美元计价，第三方整理页多以人民币标注，两边不能直接加总。看到 $30.92、$14/年这种数字，先确认是哪个套餐、哪一年的口径。

**年付不是无脑更便宜。** 折扣码循环可用、续费同享的产品，年付确实划算；但如果某个码只在首购生效，第二年按原价续，实际总成本要按两年平均算。下单前看一眼续费价那一栏。

## 退款、风险，以及官方从不明说的那部分

退款阶梯在第三方整理页里写得很具体：新购 3 天内退 80%，3 到 7 天退 50%，7 到 10 天退 20%，超过 10 天不退。这条没在官网页面找到对应佐证，下单前自己去 TOS 确认一遍比较稳妥。

还有两点整理页提到但容易被跳过：删除服务器后是退款到账户余额，不是原路退回，钱只能在平台内继续消费；特价机型可能不参与退款。买限量特供机之前，这两条要问清楚。

**不保证中国大陆直连。** 官方定位是国际互联出口，不是回国专线。电信联通走国际线路，高峰期延迟上升是常态，移动用户普遍好一些。要的是稳定低延迟访问国内资源，这台机器不合适，选香港 HKPro 或洛杉矶三网优化系列也只能改善、不能根治。

**英文支持一般。** 面板、文档、工单以中文为主，英文沟通响应慢。对中文用户不是问题，对团队里有非中文成员的情况要提前想到。

**开通快，退款窗口短。** 多数机器几分钟内开通，配合 10 天的退款上限，实际留给测试的时间只有一周多。买了当天就该跑一遍 Looking Glass 和实际业务，别拖到第八天才发现线路不对。

## 谁该买，谁别买

**适合的：**

流媒体解锁需求明确的。全节点标配 DNS 解锁，日本区实测能过 Netflix、Disney+、Dazn、Prime Video、ChatGPT，省掉自己搭解锁层的时间。

**不适合的：**

要稳定直连大陆的。官方自己说了不保证，别指望。

跑数据库或高 CPU 占用的。入门档 1 核共享，第三方测评里提到过存在 CPU Steal，实测 Geekbench 5 单核 1300 分能跑两个 Discord Bot 加一个轻量 API，再重就不合适。

要大量磁盘的。5GB 入门盘放不下任何带缓存的业务。
